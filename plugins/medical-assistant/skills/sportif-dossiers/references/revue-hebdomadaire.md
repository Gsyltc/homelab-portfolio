# Revue hebdomadaire (dimanche)

Lancée chaque dimanche par l'autopilote dédié. Elle vérifie que le programme est toujours d'actualité :

- Relire le dossier médical et les commentaires des médecins.
- Relire le suivi morphologique (`suivi-morphologie`) : évolution de l'IGC, du poids, de la masse maigre ; réajuster type d'exercices, efforts et intensité (voir « Ajustement selon la morphologie » dans `construction-programme.md`).
- Lire les retours des patients dans le dossier sportif (difficulté, facilité, ressenti, RPE, douleur, fatigue).
- Modifier ou adapter les exercices si nécessaire (progression/régression, voir `suivi-et-progression.md`).
- Re-planifier les 2 semaines à venir (au moins 1 séance le dimanche).
- Toute modification suit le versionnage et les validations (humaine + chef de clinique), étapes 1–4 de `SKILL.md`.
