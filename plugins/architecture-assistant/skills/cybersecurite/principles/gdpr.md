# GDPR — Règlement général sur la protection des données

## Vue d'ensemble

Le RGPD (Règlement (UE) 2016/679) est le cadre juridique européen pour la protection des données personnelles. Il s'applique à toute organisation qui traite des données personnelles de résidents de l'Union européenne, quelle que soit sa localisation.

## Principes fondamentaux

### 1. Licéité, loyauté et transparence
- Les données doivent être traitées de manière licite, loyale et transparente pour la personne concernée.

### 2. Limitation des finalités
- Les données doivent être collectées pour des finalités déterminées, explicites et légitimes.

### 3. Minimisation des données
- Les données doivent être adéquates, pertinentes et limitées à ce qui est nécessaire.

### 4. Exactitude
- Les données doivent être exactes et, si nécessaire, tenues à jour.

### 5. Limitation de la conservation
- Les données doivent être conservées uniquement pour la durée nécessaire.

### 6. Intégrité et confidentialité
- Les données doivent être traitées de manière à garantir leur sécurité.

### 7. Responsabilité (accountability)
- Le responsable du traitement doit être en mesure de démontrer la conformité.

## Droits des personnes concernées

| Droit | Description |
|---|---|
| Droit d'accès | Accéder à ses données personnelles |
| Droit de rectification | Corriger ses données inexactes |
| Droit à l'effacement | Demander la suppression de ses données |
| Droit à la limitation | Limiter le traitement de ses données |
| Droit à la portabilité | Recevoir ses données dans un format structuré |
| Droit d'opposition | S'opposer au traitement de ses données |
| Décisions automatisées | Ne pas être soumis à une décision automatisée |

## Obligations du responsable du traitement

- Tenir un registre des traitements.
- Réaliser une analyse d'impact (AIPD) pour les traitements à haut risque.
- Nommer un délégué à la protection des données (DPO) si nécessaire.
- Notifier les violations de données à l'autorité de contrôle dans les 72 heures.
- Informer les personnes concernées en cas de violation à haut risque.

## Sanctions

- Jusqu'à 20 millions d'euros ou 4% du chiffre d'affaires annuel mondial (le montant le plus élevé).

## Application dans l'analyse

1. Identifier si le projet traite des données personnelles de résidents UE.
2. Déterminer le rôle (responsable, sous-traitant, conjoint).
3. Évaluer les bases légales pour chaque traitement.
4. Vérifier les mesures techniques et organisationnelles de protection.
5. Documenter la conformité et les mesures mises en place.
6. Proposer des améliorations pour atteindre la conformité.
