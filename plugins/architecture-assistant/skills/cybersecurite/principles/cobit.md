# COBIT — Cadre de gouvernance et de gestion de l'IT

## Vue d'ensemble

COBIT (Control Objectives for Information and Related Technologies) est un cadre de gouvernance et de gestion de l'IT développé par l'ISACA. Il fournit un cadre complet pour la gouvernance et la gestion des technologies de l'information d'entreprise.

## Maturation COBIT

| Niveau | Description |
|---|---|
| 0 — Processus incomplet | Le processus n'est pas mis en œuvre ou ne parvient pas à atteindre ses objectifs |
| 1 — Processus initial | Le processus est mis en œuvre mais de manière ad hoc |
| 2 — Processus répétable | Le processus est documenté et suit un processus standard |
| 3 — Processus défini | Le processus est défini, documenté, communiqué et appliqué |
| 4 — Processus géré et mesurable | Le processus est surveillé et mesuré |
| 5 — Processus optimisé | Le processus est optimisé de manière continue |

## Application dans l'analyse

1. Identifier les domaines COBIT pertinents pour le projet.
2. Évaluer le niveau de maturité actuel pour chaque objectif pertinent.
3. Proposer des améliorations pour atteindre le niveau de maturité cible.
4. Vérifier que les contrôles de sécurité (APO12, DPO12, BAS05) sont correctement addressés.
5. Documenter les recommandations de gouvernance et de gestion.
6. Aligner les recommandations avec les autres normes (NIST, ISO 27001).
